# Bundle Inventory in-game verification — horizon-ctl script (one command per line).
# Drive it against a client launched with --control (or via `horizon-ctl launch`),
# inside the Xvfb recipe from the memory notes. The acceptance bar:
#   1. shift + right-click a bundle in any inventory slot (hotbar, main, off
#      hand) opens the panel left of the inventory — one slot per entry, the
#      vanilla slot frames and item rendering, the weight bar under the grid;
#   2. clicking an entry takes that entry onto the cursor (the selection is
#      set first, so the take is exactly that entry, not the first);
#   3. shift-clicking an entry moves it into the inventory — merging onto
#      partial stacks first, then empty slots, main before hotbar — and what
#      no slot took goes back into the bundle, not onto the cursor;
#   4. clicking an inventory item with the panel open inserts it into the
#      bundle (what fits; the remainder back in its slot); a shulker box or
#      a full bundle just plays vanilla's insert-fail behavior and moves
#      nothing;
#   5. Q over an entry drops it into the world; Q elsewhere keeps vanilla's
#      drop-a-slot behavior; Escape closes the panel and NOT the inventory;
#   6. a click outside the panel (with the panel open) closes it and never
#      drops what the cursor carries;
#   7. the bundle's own slot stays vanilla's while the panel is open
#      (right-click takes one out, a carried stack clicked onto it inserts);
#   8. closing the inventory (E) closes the panel; moving the bundle out of
#      its slot (vanilla click, another mod) closes it too;
#   9. Options > Mods > Bundle Inventory: Enabled OFF — shift + right-click
#      does nothing, vanilla right-click behavior returns;
#  10. on a server: the same, because every move is an ordinary inventory
#      click plus the vanilla SelectBundleItem packet for the take/drop of a
#      chosen entry (the wheel's own protocol).
# Deferred (the release-rebuild fence forbids launching the client): run this
